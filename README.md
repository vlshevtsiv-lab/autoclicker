# autoclicker

Auto Clicker (Python Tkinter)
Description

This project is a simple Auto Clicker built with Python and Tkinter. It allows the user to automatically click the mouse at a specified rate. The application includes a clean graphical interface and hotkeys for user convenience. It is useful for automation tasks or as a beginner project to learn GUI programming and event handling in Python.

Features

Simulate mouse clicks at a user-defined speed (clicks per second)

Start and stop the auto clicker using buttons or the ESC key

Display messages and error handling via pop-ups (tkinter.messagebox)

Hotkey integration with the keyboard library

Beginner-friendly GUI design using Tkinter

How to Run

Make sure Python 3 is installed.

Install required libraries if you don’t have them:

pip install mouse keyboard


Save the script (e.g., auto_clicker.py).

Run the program:

python auto_clicker.py


Enter the number of clicks per second in the input field and press Почати to start.

Press ESC or click Вийти to stop and exit the program.

Press i for information about the program.

Learning Goals

Build GUIs with Tkinter

Work with mouse automation using the mouse library

Handle keyboard shortcuts with the keyboard library

Implement event-driven programming and input validation
